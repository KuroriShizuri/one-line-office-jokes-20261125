One line, 102 characters: the Monday standup in a single sentence — fourteen people, zero blockers, everybody visibly, gloriously blocked.

> Monday standup is fourteen people taking turns saying "no blockers" while visibly, gloriously blocked.

`main.py` (Python standard library only) writes that single line to `entry.txt` and validates it first: exactly one line, under 200 characters, then re-reads the file as bytes to confirm it matches exactly.

## Run it

```sh
python3 main.py
```
